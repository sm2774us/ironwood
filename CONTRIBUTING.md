# Contributing
1. `nvm use && npm ci`
2. `npm run dev` (web :5173, API :3001)
3. Before pushing: `npm run verify`
4. Conventional commits; PRs ≤ ~400 lines; fill in the PR template; add an ADR for architectural changes.
5. Reviews: comments must be actionable (what, why, suggested change); blocking vs. nit labelled explicitly.
